# دليل استخدام أتمتة الواتساب SLC

## نظرة عامة
هذا البرنامج يتيح لك إرسال رسائل تلقائية إلى مجموعات الواتساب فقط (وليس للأرقام الفردية) بشكل مجدول أو فوري.

## المتطلبات
- Windows 10 أو أحدث
- Node.js مثبت على النظام
- حساب واتساب نشط
- اتصال بالإنترنت

## الإعداد الأولي

### 1. التحضير
- قم بتشغيل `SETUP.bat` لتثبيت المكتبات المطلوبة
- أو شغل `MENU.bat` واختر الخيار رقم 1

### 2. إعداد المجموعات
- افتح ملف `groups.txt`
- أضف أسماء المجموعات (اسم واحد في كل سطر)
- مثال:
```
مجموعة العمل
أصدقاء الجامعة
العائلة
```

### 3. إعداد الرسالة
- افتح ملف `message.txt`
- اكتب النص الذي تريد إرساله
- يمكنك استخدام النصوص العربية والإنجليزية

### 4. إعداد التوقيت
- افتح ملف `.env`
- غير `CRON_SCHEDULE` حسب التوقيت المطلوب
- الإعداد الافتراضي: `0 21 * * *` (9:00 مساءً يومياً)

## طرق التشغيل

### الطريقة الأولى: القائمة التفاعلية
1. شغل `MENU.bat`
2. اختر الوظيفة المطلوبة من القائمة

### الطريقة الثانية: التشغيل المباشر
- `SETUP.bat` - الإعداد الأولي
- `start.bat` - التشغيل مع الجدولة اليومية
- `send-now.bat` - الإرسال الفوري

## أول استخدام

### خطوات المسح الضوئي
1. شغل أي من أوامر التشغيل
2. ستظهر نافذة متصفح
3. امسح رمز QR بهاتفك
4. سيتم حفظ الجلسة تلقائياً

## الميزات الأمنية

### الحماية من الحظر
- تأخير 3 ثوانٍ بين كل رسالة
- إرسال للمجموعات فقط (لا أرقام فردية)
- تسجيل جميع العمليات

### إعدادات الأمان في `.env`
```
DELAY_BETWEEN_MESSAGES=3000  # تأخير بالميلي ثانية
```

## ملفات المشروع

### الملفات الرئيسية
- `groups.txt` - أسماء المجموعات
- `message.txt` - نص الرسالة
- `.env` - الإعدادات
- `logs/app.log` - سجل العمليات

### ملفات التشغيل
- `MENU.bat` - القائمة الرئيسية
- `SETUP.bat` - الإعداد الأولي
- `start.bat` - التشغيل المجدول
- `send-now.bat` - الإرسال الفوري

## استكشاف الأخطاء

### مشاكل شائعة

#### لا يتم العثور على المجموعات
- تأكد من صحة أسماء المجموعات في `groups.txt`
- استخدم جزء من اسم المجموعة بدلاً من الاسم كاملاً

#### مشاكل المسح الضوئي
- أغلق جميع نوافذ الواتساب ويب
- امسح ملف `session.json` إذا وُجد
- أعد تشغيل البرنامج

#### مشاكل التثبيت
- تأكد من تثبيت Node.js
- شغل Command Prompt كمسؤول
- أعد تشغيل `SETUP.bat`

### عرض السجلات
- استخدم `MENU.bat` واختر خيار عرض السجلات
- أو افتح `logs/app.log` مباشرة

## جدولة التوقيت

### أمثلة على CRON
```
0 21 * * *    # يومياً في 9:00 مساءً
0 9 * * *     # يومياً في 9:00 صباحاً
0 21 * * 1    # كل اثنين في 9:00 مساءً
0 21 1 * *    # أول كل شهر في 9:00 مساءً
*/30 * * * *  # كل 30 دقيقة
```

## النقل والتوزيع

### نسخ المشروع
1. انسخ المجلد كاملاً
2. شغل `SETUP.bat` في المكان الجديد
3. أعد إعداد المجموعات والرسائل

### متطلبات النظام الجديد
- Node.js مثبت
- اتصال إنترنت نشط
- إعادة مسح QR Code

## الدعم والمساعدة

### في حالة مواجهة مشاكل
1. راجع ملف `logs/app.log`
2. تأكد من الاتصال بالإنترنت
3. أعد تشغيل البرنامج
4. امسح جلسة الواتساب وأعد المسح

### نصائح للاستخدام الأمثل
- لا تترك البرنامج مفتوحاً لفترات طويلة دون استخدام
- راجع الرسائل قبل الإرسال
- تأكد من أسماء المجموعات دورياً
- احتفظ بنسخة احتياطية من إعداداتك
